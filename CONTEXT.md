# Sequential Gallery for Grasshopper

Compare Grasshopper-generated designs and explore them through user preferences. Terms follow `spec.md`, including decisions confirmed during implementation and rendering design discussions.

## Language

**Design variable**:
A standard Number Slider connected directly to the Variables input. SPS uses continuous coordinates normalized to 0-1; values are rounded to the slider's existing numeric type and precision only when applied.

**Candidate**:
A design-variable combination associated with a coordinate on the search plane, together with a viewport image of the Grasshopper model recomputed using those values.

**Search plane**:
A two-dimensional subspace of the design-variable space generated by the authors' Sequential Plane Search (SPS) implementation.

**Gallery grid**:
The row and column counts chosen before starting exploration, each 3, 5, 7, or 9, with a default of 5x5. Odd counts retain a center candidate. The grid is fixed for one session; it changes the sampling density, while SPS and the four-selection, 2x zoom procedure remain unchanged.

**Zoom level**:
A stage of selecting a candidate and halving the search region around it on the same plane. The fourth selection is submitted to SPS to construct the next search plane.

**Final candidate**:
The last candidate selected by the user, whose applied slider values are restored when finishing normally.

**AI rendering component**:
A separate Grasshopper component for exploring the rendering atmosphere of a fixed reference image. It has its own setup and exploration session; integration with the geometry exploration workflow is a future goal.

**Rendering reference image**:
The single capture of the active Rhino viewport taken when the user starts an AI rendering session. It remains fixed throughout that session and is the reference for every generated matrix.

**Initial prompt**:
The desired shared scene conditions entered before an AI rendering session starts, such as preserving the storey count and camera angle. The text stays fixed across all candidate matrices and, together with Negative prompt, takes priority over conflicting atmosphere instructions without becoming a search variable.

**Negative prompt**:
The unwanted results to avoid across every cell and iteration of an AI rendering session, such as altered geometry, unequal cells, watermarks, extra text, or Rhino viewport overlays. It is captured on Start alongside Initial prompt and included in its own avoidance block in every API prompt, outside the search variables.

**Rendering search session**:
An independent SPS exploration over two through six selected rendering variables (TimeOfDay, RenderingStyle, Weather, Activity, Vegetation, and Season), using 2x zoom and a plane update after four committed selections. Its gallery axes represent SPS coordinates and need not correspond to individual variables.

**Fixed rendering value**:
The anchor chosen before Start for a rendering variable excluded from SPS exploration: one of five catalog conditions, or one of four seasons. It remains identical in every candidate throughout the session and is shown as fixed in inspector details.

**Rendering matrix**:
A single AI-generated image containing the candidate cells for one rendering search step. It uses the session's gallery grid, defaulting to 5x5 with rows and columns independently chosen from 3, 5, 7, or 9 before Start.

**Rendering selection**:
The currently highlighted cell and its associated parameter vector in the displayed rendering matrix. Clicking changes this selection; Next commits it to SPS and advances exploration.

**Out-of-range rendering cell**:
A rendering matrix slot whose SPS vector contains a non-finite value or a variable outside its defined 0-1 semantic range. The slot stays in place, is covered by an `Out of range` overlay, and cannot be selected.

**RenderingStyle**:
The rendering variable ordered from monochrome pencil linework on textured paper (0), through lightly watercolor-tinted hand-drawn sketch (0.25), painterly architectural illustration (0.5), and recognizably computer-generated architectural visualization (0.75), to photorealistic architectural photography (1). Intermediate values describe weighted blends of neighboring styles while remaining continuous SPS coordinates.

**TimeOfDay**:
The rendering variable ordered from just after dawn (0), through mid-morning (0.25), noon (0.5), and post-sunset magic hour (0.75), to night (1). Intermediate explored values describe transitions between adjacent lighting conditions; fixed values use a chosen anchor, defaulting to noon.

**Season**:
The rendering variable ordered linearly from spring (0), through summer (1/3) and autumn (2/3), to winter (1), without wrapping winter to spring. It controls seasonal appearance and precipitation type under bad weather; a fixed Season uses one chosen season, defaulting to autumn (2/3).

**Weather**:
The continuous rendering variable from good weather (0) to bad weather (1). Bad-weather precipitation is rain in spring, summer, and autumn, transitioning continuously through sleet between autumn and winter to snow in winter; winter alone does not request snow.

**Final rendering preview**:
The selected rendering cell cropped from its matrix and displayed after Finish, at the generated resolution. The user can save that crop as a PNG without generating a new image or upscaling it.

**Pending rendering generation**:
The fixed reference image, candidate conditions, grid mapping, prompt, and output settings awaiting a successful AI matrix response. Retry resends these conditions without adding another SPS selection or advancing the search again.
