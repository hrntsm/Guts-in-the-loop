# Sequential Gallery for Grasshopper

Compare Grasshopper-generated designs and explore them through user preferences. Terms follow `spec.md` version 2.0, including the decisions agreed during implementation.

## Language

**Design variable**:
A standard Number Slider connected directly to the Variables input. SPS uses continuous coordinates normalized to 0-1; values are rounded to the slider's existing numeric type and precision only when applied.

**Candidate**:
A design-variable combination associated with a coordinate on the search plane, together with a viewport image of the Grasshopper model recomputed using those values.

**Search plane**:
A two-dimensional subspace of the design-variable space generated by the authors' Sequential Plane Search (SPS) implementation.

**Zoom level**:
A stage of selecting a candidate and halving the search region around it on the same plane. The fourth selection is submitted to SPS to construct the next search plane.

**Final candidate**:
The last candidate selected by the user, whose applied slider values are restored when finishing normally.
