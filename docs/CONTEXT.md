# Sequential Gallery for Grasshopper

Compare Grasshopper-generated designs and explore them through user preferences. Terms follow `spec.md`, including decisions confirmed during implementation and rendering design discussions.

## Language

**Evaluate mode**:
The tab containing the current candidate grid and the existing selection workflow for an exploration session.

**History mode**:
The tab showing recorded candidate grids and branches, from which the user can return to an earlier exploration step. Integrated exploration places geometry and AI histories in two connected columns identifying each geometry handoff.

**Exploration branch**:
A retained path of exploration steps descended from earlier candidate selections. Revising a choice at an earlier step creates a new branch while preserving the previous path for later navigation.

**History node**:
One displayed candidate grid at a particular exploration step, including intermediate zoom stages. It identifies a point from which the corresponding exploration state can be restored.

**Completed finishing choice**:
A candidate explicitly confirmed in Evaluate or committed through Next, identified by its source history node and cell. It is eligible for finishing without requiring another generated grid.

**Regeneration variant**:
An AI rendering history node containing a newly generated matrix for the same candidate conditions and optimizer state as its source node. The source remains available, and either image variant can be used to continue exploration without treating regeneration itself as a preference selection.

**Design variable**:
A standard Number Slider connected directly to the Variables input. SPS uses continuous coordinates normalized to 0-1; values are rounded to the slider's existing numeric type and precision only when applied.

**Candidate**:
A design-variable combination associated with a coordinate on the search plane, together with a viewport image of the Grasshopper model recomputed using those values.

**Search plane**:
A two-dimensional subspace of the design-variable space generated by the authors' Sequential Plane Search (SPS) implementation.

**Gallery grid**:
The row and column counts chosen before starting exploration, each 3, 5, 7, or 9, with a default of 5x5. Odd counts retain a center candidate. The grid is fixed for one session; it changes the sampling density, while SPS and the four-selection, 2x zoom procedure remain unchanged.

**Zoom level**:
A stage of selecting a candidate and halving the search region around it on the same plane. Boundary adjustment can move the selected candidate away from the grid center. The fourth selection is submitted to SPS to construct the next search plane.

**Bounded sampling window**:
The continuous rectangle in the author's two-dimensional plane coordinates used to generate a gallery. Keep a requested zoom unchanged when its entire rectangle maps into 0-1 for every variable. Otherwise translate it into the previous certified window while preserving its width and the selected point; shrink only if needed for an unusable fresh plane or numerical fallback. Store the corrected window with optimizer snapshots so display, selection, learning, and History agree. Individual variable coordinates are never clamped.

**Final candidate**:
The candidate selected for geometry-only completion, or the geometry choice explicitly selected in History for a combined final render. It may differ from the original geometry used to explore the selected rendering conditions. Its recorded applied slider values are restored when finishing.

**AI rendering component**:
The legacy AI-only entry point retained for existing Grasshopper definitions. New definitions use the integrated Sequential Gallery component, which provides AI-only behavior when no design variables are connected.

**Integrated exploration**:
The single-component workflow showing geometry optimization on the left and AI rendering optimization on the right. With no connected design variables it provides AI rendering only; combined history identifies which geometry result supplied each rendering reference.

**Geometry handoff**:
The explicit `Use this shape` action that supplies a chosen geometry candidate as the AI rendering reference. That reference remains fixed until another handoff, while geometry exploration can continue independently.

**Rendering reference image**:
The fixed image used by every matrix in one rendering exploration: the handed-off geometry candidate's recorded capture in combined mode, or the active viewport captured on Start in AI-only mode. Returning to a prior exploration restores its original reference.

**Initial prompt**:
The desired shared scene conditions entered before an AI rendering session starts, such as preserving the storey count and camera angle. The text stays fixed across all candidate matrices and, together with Negative prompt, takes priority over conflicting atmosphere instructions without becoming a search variable.

**Negative prompt**:
The unwanted results to avoid across every cell and iteration of an AI rendering session, such as altered geometry, unequal cells, watermarks, extra text, or Rhino viewport overlays. It is captured on Start alongside Initial prompt and included in its own avoidance block in every API prompt, outside the search variables.

**Rendering search session**:
An independent SPS exploration over two through six selected rendering variables (TimeOfDay, RenderingStyle, Weather, Activity, Vegetation, and Season), using 2x zoom and a plane update after four committed selections. Its gallery axes represent SPS coordinates and need not correspond to individual variables.

**Fixed rendering value**:
The anchor chosen before Start for a rendering variable excluded from SPS exploration: one of five catalog conditions, or one of four seasons. It remains identical in every candidate throughout the session and is shown as fixed in inspector details.

**Rendering matrix**:
A single AI-generated image containing the candidate cells for one rendering search step. It uses the session's gallery grid, defaulting to 5x5 with rows and columns independently chosen from 3, 5, 7, or 9 before Start.

**Rendering selection**:
The currently highlighted cell and its associated parameter vector in the displayed rendering matrix. Clicking changes this selection; Next commits it to SPS and advances exploration.

**Out-of-range rendering cell**:
A defensive rendering matrix slot whose SPS vector contains a non-finite value or a variable outside its defined 0-1 semantic range. Ordinary boundary exploration instead uses a bounded sampling window and generates all cells. An unexpected invalid slot stays in place, is covered by an `Out of range` overlay, and cannot be selected.

**RenderingStyle**:
The rendering variable ordered from monochrome pencil linework on textured paper (0), through lightly watercolor-tinted hand-drawn sketch (0.25), painterly architectural illustration (0.5), and recognizably computer-generated architectural visualization (0.75), to photorealistic architectural photography (1). Intermediate values describe weighted blends of neighboring styles while remaining continuous SPS coordinates.

**TimeOfDay**:
The rendering variable ordered from just after dawn (0), through mid-morning (0.25), noon (0.5), and post-sunset magic hour (0.75), to night (1). Intermediate explored values describe transitions between adjacent lighting conditions; fixed values use a chosen anchor, defaulting to noon.

**Season**:
The rendering variable ordered linearly from spring (0), through summer (1/3) and autumn (2/3), to winter (1), without wrapping winter to spring. It controls seasonal appearance and precipitation type under bad weather; a fixed Season uses one chosen season, defaulting to autumn (2/3).

**Weather**:
The continuous rendering variable from good weather (0) to bad weather (1). Bad-weather precipitation is rain in spring, summer, and autumn, transitioning continuously through sleet between autumn and winter to snow in winter; winter alone does not request snow.

**Rendering crop**:
A candidate cell extracted from an exploration matrix at its original resolution. It is distinct from a newly generated full-size final render.

**Final render**:
A newly generated standalone image using a geometry choice and rendering conditions selected from History. It is distinct from exporting an existing matrix cell as a crop.

**Pending rendering generation**:
The fixed reference image, candidate conditions, grid mapping, prompt, and output settings awaiting a successful AI matrix response. Retry resends these conditions without adding another SPS selection or advancing the search again.
